This release introduces remote library browsing for downloading books without syncing reading progress, a floating control bar for auto-scrolling, and a new home-screen widget to browse your library covers.

### Reading

* Auto-scroll can now be toggled directly under "Read by scrolling" in the main reading settings, and a floating bar appears on the page while auto-scrolling to pause, adjust speed, or stop ([#266](https://github.com/chmouel/liseur/pull/266)). Pausing or stopping immediately saves your spot on the page, and tapping speed controls multiple times in quick succession registers every tap.

<img src="https://github.com/user-attachments/assets/22347c50-3d7a-4a03-ad0c-52e8e9b67f7e" alt="Auto-scroll floating control bar" width="320">

### Library

* You can now save and browse extra catalogs—including calibre-web, Komga, BookOrbit, OPDS feeds, or Project Gutenberg—and download individual titles or full categories ([#261](https://github.com/chmouel/liseur/pull/261), [#262](https://github.com/chmouel/liseur/pull/262)). Books downloaded from these sources remain local to your device and never send reading progress or edits back to the remote server or KOReader sync.

<img src="https://github.com/user-attachments/assets/f1a6f42b-8f51-4a0d-bc56-b09eb7d08075" alt="Remote libraries screen" width="320">

* The "Start with free books" card now opens Project Gutenberg as a saved remote catalog, allowing you to browse by language or category and pick specific books ([#262](https://github.com/chmouel/liseur/pull/262)). Existing Gutenberg starter shelves are automatically converted on update without losing downloaded books or reading progress.

<img src="https://github.com/user-attachments/assets/85598ab3-f5e2-4bf8-b4d9-63f5cbb4c540" alt="Gutenberg catalog under remote libraries" width="320">

* A new "Your books" home-screen widget displays book covers from your library with paging arrows ([#265](https://github.com/chmouel/liseur/pull/265)). Tapping a cover opens the book, downloading it first if needed, while tapping the header opens the library.

<img src="https://github.com/user-attachments/assets/a01cc8df-fe60-4617-82a1-3213f3146b37" alt="Home-screen widgets" width="320">

* Reading-time widgets now fetch reading updates from other devices in the background after a sync and indicate whether their totals cover all devices, older synced data, or only the current phone ([#265](https://github.com/chmouel/liseur/pull/265)).

### Fixes

* Tapping covers on the library widget in rapid succession now ignores earlier taps so the correct book opens once the library loads.
* Widget shortcuts now use private launch intents to prevent other apps from triggering unauthorized book downloads or opens.
* Sync updates completed while widgets are already refreshing now schedule a single follow-up refresh rather than triggering repetitive background statistics recalculations.
* Reading widgets no longer display "All devices" when showing reading streaks derived from older synced data.

### Under the hood

* Release notes now contain signing certificate fingerprints and verification details to verify package authenticity ([#264](https://github.com/chmouel/liseur/pull/264)).
